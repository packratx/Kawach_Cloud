# Security Policy

## Supported versions
This project is in active development. Security issues should be reported even if the version is not yet final.

## Reporting a vulnerability
Please do not open a public issue for a potential security vulnerability.

Use the project contact channel or email the maintainer privately:
- Aravind(guru)
- darkwebaccess404@gmail.com

Please include:
- the issue description
- reproduction steps if known
- affected version or commit
- any relevant screenshots, logs, or code references

## Security expectations
- never commit secrets
- never log Telegram auth data, OTPs, passcodes, or keys
- never create developer backdoors or hidden recovery keys
- never claim stronger privacy than the implementation can technically provide

## Response policy
We will review valid reports as quickly as possible and coordinate on a remediation plan.
